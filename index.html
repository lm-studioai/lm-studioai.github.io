LM Studio Features

LM Studio is built for users who want a graphical, no-command-line experience for running local models, with the flexibility of a local API when you need to build.

Desktop App for Local LLMs

LM Studio is a full desktop application for developing and experimenting with LLMs on your computer, with a clean interface for browsing, downloading, and running models [citation:3].

Fully Offline Operation

Once you have models downloaded, LM Studio can run entirely offline. Chat, document RAG, and the local server all work without an internet connection [citation:7].

OpenAI-Compatible Local API

LM Studio can serve a local REST API that mimics OpenAI endpoints, allowing you to connect your own applications and scripts. The default endpoint is http://localhost:1234/v1, and no API key is required for local use [citation:4][citation:15].

Document Chat (RAG)

You can attach documents to your chat messages and interact with them entirely offline. Document processing stays on your machine and never leaves the application [citation:3][citation:7].

Model Browser Built In

Search and download models directly within the app. LM Studio supports llama.cpp (GGUF) on all platforms and MLX on Apple Silicon Macs [citation:3].

Broad Platform Support

LM Studio is available for Apple Silicon Macs, x64 and ARM64 Windows PCs (including Snapdragon X Elite), and x64/ARM64 Linux systems [citation:6][citation:11].

What Is LM Studio?

LM Studio is a desktop application for running LLMs locally. Unlike command-line-first tools, it provides a graphical interface for every step of the workflow: discovering models, downloading them, configuring runtimes, and chatting — with the option to expose a local API for development.

Graphical Local Runtime

LM Studio manages model downloads, runtime configuration, and inference through a desktop UI. You can install or switch LLM runtimes without fully updating the app [citation:7].

llama.cpp and MLX

On Windows and Linux, LM Studio uses llama.cpp for GGUF models. On Apple Silicon Macs, it also supports MLX for optimized local inference [citation:3].

Local-First Design

The app is designed for local experimentation and development. Network connections are only needed for browsing and downloading models, or for optional runtime downloads [citation:7].

How To Install LM Studio

Installation is straightforward on all supported platforms. The app is available as a standard installer on Windows and macOS, and as an AppImage on Linux.

1

Download For Your Platform

Visit lmstudio.ai/download and choose your operating system. Windows and macOS get standard installers; Linux uses an AppImage [citation:1][citation:5].

2

Install & Launch

Run the installer or AppImage. On first launch, LM Studio provides a model browser and a chat interface ready to use.

3

Download A Model

Use the in-app search to find a model (for example Llama, Qwen, Mistral, Gemma, or DeepSeek), then click download. Model files can range from a few gigabytes upward [citation:3].

4

Load, Chat, or Serve

Load the model and start chatting in the app. To use the API, start the local server (default port 1234) and point your application at http://localhost:1234/v1 [citation:15].

System Requirements

LM Studio runs on modest hardware for smaller models, but larger models need more RAM and VRAM. The official documentation provides platform-specific guidance.

Windows

x64 systems require AVX2 instruction set support. ARM (Snapdragon X Elite) is also supported. At least 16GB RAM is recommended, and a GPU with at least 4GB dedicated VRAM is recommended [citation:6][citation:11].

macOS

Requires Apple Silicon (M1/M2/M3/M4) and macOS 14.0 or newer. 16GB+ RAM recommended. Intel-based Macs are currently not supported [citation:6][citation:11].

Linux

x64 and ARM64 (aarch64) are supported. Distributed as an AppImage. Ubuntu 20.04 or newer is required. x64 builds ship with AVX2 support by default [citation:11].

Common Considerations

Model Downloads Require Internet

While inference runs offline, searching and downloading models requires an internet connection to reach model repositories such as Hugging Face [citation:7].

VRAM and Model Size

Larger models require more VRAM or system RAM. If a model doesn't fit in dedicated VRAM, performance may drop as layers spill to system memory.

Runtime Management

LM Studio 0.3.0 and later allow LLM runtimes to be downloaded and switched independently of the main app, so you can update the inference engine without a full app update [citation:7].
